No account or phone number is required to use Speakeasy, and there are no
demo credentials to request. Sign-up is anonymous: the app verifies the
DEVICE, not a person.

Getting in:
1. Launch the app and tap "Open the door."
2. The app generates an anonymous cryptographic identity on-device and asks
   you to pick a handle (e.g. @reviewer) and a face/avatar. That's the whole
   sign-up — nothing is sent off the device about who you are.
3. Tapping "This one's mine" verifies the device (Face ID / Touch ID / device
   passcode). Verification is hardware-backed attestation only — there is no
   email or SMS code fallback — so please test on a device with a passcode
   (and Face ID / Touch ID) enabled.

Testing messaging + calls (needs two installs):
4. Install on a second device (or a second TestFlight install). On each,
   open the handle screen to see your @handle + QR code.
5. On device A, add device B by scanning B's QR (or pasting B's handle), then
   start a chat or a Private Call.
6. All messages and calls are end-to-end encrypted (Signal Protocol); calls
   additionally apply a voice-masking filter. The server only ever sees
   ciphertext.

Notes:
- Speakeasy verifies your device with a passkey. Please review on a physical device with a screen lock set (not an emulator). Device verification requires secure hardware; on a capable device, sign-in completes with the device passkey.
- There is no reviewer code and no email; the app requires a passkey-capable device.
- Private Calls require microphone permission; messaging needs no special
  permissions.
- There is no central directory — you can only reach someone whose handle or
  QR you already have, by design.
